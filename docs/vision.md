# Vision

My Gyazo is a personal Windows screenshot and annotation tool. The core flow is to select an area, quickly draw rectangles or add text to highlight what matters, then save the image locally and have it ready to paste. Captures should be easy to find later without an account or upload.

We are heading toward a reliable, quiet desktop companion that makes simple image markup feel effortless. Annotation should be available immediately after capture, with clear controls and as few steps as possible. Improvements to capture, markup, browsing, and recovery from errors should keep the interface small and the user's files under their control.

In the future, the same workflow should work on a phone. A mobile capture should be easy to send to the laptop over a private connection, with Tailscale as a possible route. From the app, users should be able to choose where an image goes: the usual capture library, a specific folder, or a repository they are working on. Destinations should be easy to add without making the everyday capture flow more complicated. New features should earn their place by shortening the path from seeing something to sharing or using it.
